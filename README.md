## Dokumentasi Kegiatan Workshop 
Rangkuman materi :

Pembawaan materi yang berjudul "From AI to GitHub" dibawakan oleh Bang Nugi. yang menjelaskan bahwa tools AI yang sering kita pakai seperti Gemini, Claude, Orca, Grok, dan GPT sangat berguna untuk proses pengembangan proyek.Git dan GitHub berperan sebagai platform untuk mengelola riwayat perubahan kode serta mempermudah kolaborasi tim.dan juga membahas seputar Prompt Engineering. Secara sederhana, prompt adalah instruksi yang kita berikan kepada model AI untuk mendapatkan hasil yang spesifik. Pembuatan prompt tidak boleh sembarangan. Tanpa konteks yg jelas, AI akan kesulitan memahami maksud kita dan cenderung memberikan jawaban yang kurang relevan. Oleh karena itu, diajarkan pula kerangka prompt yang ideal, yang harus mencakup Role, Task , Context , dan Format Output.Selanjutnya, materi beralih ke pengenalan Git dan GitHub.Git merupakan version control system yang berfungsi untuk melacak riwayat revisi sebuah file mulai dari siapa yang mengedit, kapan diubah, hingga apa saja bagian yang direvisi.kita juga belajar fungsi-fungsi dasarnya, seperti cara membuat repository baru, memindahkan file, menyimpan file ke repository, hingga melihat riwayat perubahan. Tidak hanya teori, kita diajarkan langkah-langkah praktis mulai dari menginstal Git, mengatur (setup) Visual Studio Code (VS Code), hingga menghubungkannya langsung dengan akun GitHub. Rangkaian acara kemudian ditutup dengan sesi praktik menyusun prompt yang berkonteks lengkap untuk merancang sebuah halaman web menggunakan HTML.

## Point Point penting 

- Memahami penggunaan berbagai tools AI (seperti Gemini, Claude, Grok, dan GPT) untuk membantu dan mempercepat proses pembuatan suatu proyek.

- Mengetahui cara teknik prompt engineering yang benar  menggunakan kerangka dasar yang meliputi Role, Task, Context,dan Format Output.

- Pengenalan Konsep Dasar Git dan GitHub Memahami fungsi Git sebagai version control system untuk melacak riwayat perubahan kode (siapa yang mengedit, kapan, dan    apa yang diubah), serta GitHub sebagai platform untuk menyimpan repository dan berkolaborasi.

- Praktik workshop mempelajari langkah-langkah teknis mulai dari menginstal Git, mengatur (setup) Visual Studio Code, hingga cara menghubungkannya langsung dengan   akun GitHub.
